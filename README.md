## 👋 About this repository

This repository documents my practice on [Exercism](https://exercism.org/). I use coding challenges to strengthen my programming fundamentals, develop problem-solving skills, and build confidence writing code independently.

My current focus is **Java**, especially **object-oriented programming (OOP)**. Over time, I may add solutions in other languages.

## 🎯 Learning goals

- Build a strong foundation in Java syntax and core concepts.
- Understand OOP: classes, objects, methods, encapsulation, inheritance, and polymorphism.
- Practice data structures, algorithms, and clean code.
- Write code independently, test it, and learn from mistakes.
- Keep a visible record of my progress.

## 📚 My approach

1. Read the exercise instructions and understand the expected behavior.
2. Design and implement a solution without copying one.
3. Run the provided tests and investigate failures.
4. Refactor when I find a clearer or simpler approach.
5. Submit my solution and reflect on what I learned.

## 🧪 Running Java exercise tests

From the root directory of a downloaded Java exercise, run the Gradle Wrapper:

```powershell
.\gradlew.bat test
```

The exact project files and requirements may vary from one exercise to another.
